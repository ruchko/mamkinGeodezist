# mamkinGeodezist

Набор небольших утилит для работы с геодезическими данными: расчёта объёмов земляных работ и конвертации между CSV и SDR-форматом для тахеометров Sokkia .

## Что делает проект

Проект предназначен для обработки точек рельефа, представленных в координатах X/Y/Z, и для обмена данными между популярными геодезическими форматами.

## Скрипты

### 1. `calculateVolume.py`

Скрипт рассчитывает объёмы выемки и насыпи относительно заданной проектной отметки.

Как работает:
- читает CSV-файл с колонками `Easting`, `Northing`, `Elevation`;
- строит триангуляцию поверхности по точкам с помощью `Delaunay`;
- сравнивает высоты с заданной целевой отметкой;
- рассчитывает объём выемки (cut) и насыпи (fill);
- создаёт VRML-файл `.wrl` с визуализацией рельефа и плоскостей.

Пример запуска:

```bash
python calculateVolume.py data.csv
python calculateVolume.py data.csv 123.45
```

- Если высота не указана, берётся максимальная отметка по рельефу.
- Выходной файл сохраняется рядом с исходным CSV в формате `.wrl`.

Пример структуры CSV:

```csv
Easting,Northing,Elevation
100,200,12.3
101,200,12.5
100,201,12.1
```

---

### 2. `convertCsvToSdr.py`

Скрипт конвертирует CSV-таблицу в SDR33-совместимый формат.

Поддерживает:
- разделители `,` и `;`;
- колонки с именами точек: `Name`, `PointID`, `Taškas`, `ID`;
- координаты в полях `X`, `Y`, `Z` или `H`.

Пример запуска:

```bash
python convertCsvToSdr.py points.csv
```

На выходе будет создан файл `points.sdr` рядом с исходным CSV.

---

### 3. `convertSdrToCsv.py`

Скрипт выполняет обратную конвертацию: читает SDR-файл и сохраняет точки в CSV.

Результат записывается в таблицу со столбцами:

```csv
PointID,Easting,Northing,Elevation
```

Пример запуска:

```bash
python convertSdrToCsv.py input.sdr
python convertSdrToCsv.py input.sdr output.csv
```

- `calculateVolume.py` — расчёт объёмов земляных работ и визуализация модели.

- `convertSdrToCsv.py` — импорт SDR в CSV для дальнейшей обработки.
